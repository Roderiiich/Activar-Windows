# 🛠️ Windows KMS Activator Scripts

Una colección de scripts de procesamiento por lotes (`.bat`) automatizados para configurar y activar distintas ediciones de Windows (10 y 11) mediante servidores KMS públicos.

> **Nota:** Diseñado y personalizado por **Roderich**.

---

## 📋 Ediciones Compatibles

Los scripts incluidos en este repositorio están adaptados para las siguientes ediciones de Windows 10 / 11:

- 🔹 Windows Home / Core
- 🔹 Windows Home Single Language
- 🔹 Windows Pro
- 🔹 Windows Enterprise
- 🔹 Windows Education
- 🔹 Windows Pro for Workstations

---
## 📋 Modo de Uso

- 🔹Descarga el archivo que sea compatible con tu version de Windows.
- 🔹Luego haz click derecho y Ejecuta como Administrador y listo.
